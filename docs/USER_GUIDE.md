## 1. 登录

访问系统首页 `/login`，可见「桑格查重后台管理系统」登录页。

系统支持两种登录方式：

### 1.1 账号密码登录

1. 切换到 **账号密码登录** Tab
2. 输入 **邮箱** 与 **密码**
3. 点击「登录」按钮

登录成功后系统会根据账号身份自动跳转：

- 管理员 / 超级管理员（token 以 `Bearer` 开头）→ 跳转 `/dashboard`
- 商户（token 不以 `Bearer` 开头）→ 跳转 `/merchant/control/information`

### 1.2 微信扫码登录

1. 切换到 **微信扫码登录** Tab
2. 使用微信扫描页面中显示的二维码
3. 在手机端确认后，系统会自动轮询登录状态并跳转

> 若账号无管理员/商户权限，扫码后将提示「登录失败」。

### 1.3 登录态与超时

- 登录信息会持久化保存在浏览器 `localStorage`，关闭浏览器后无需重新登录。
- **空闲 30 分钟** 未任何鼠标/键盘/滚动/点击操作，系统将自动登出并跳回登录页。
- 后端返回 401 时也会自动清空登录态并跳转登录页。

## 2. 系统总览（管理员）

### 2.1 仪表盘 `/dashboard`

进入管理员后台首页即可看到仪表盘，包含：

- **订单统计卡片**：今日单量/金额、本月单量/金额、累计单量/金额
- **异常订单概览**：CrossCheck / Imagetwin / Turnitin / SangerboxScope 各自的异常订单数量，点击可跳转到对应异常订单页
- **趋势图表**：按月份展示订单趋势
- **刷新按钮**：手动重新拉取统计数据

> 异常订单数量会同步显示在左侧菜单对应项的红点徽标上。

### 2.2 顶栏功能

从左到右依次为：

| 按钮 | 功能 |
| --- | --- |
| 折叠/展开菜单 | 收起或展开左侧侧边栏 |
| 进入/退出全屏 | 切换浏览器全屏模式 |
| ☀️ / 🌙 切换 | 浅色 / 深色主题切换 |
| 当前余额（仅商户可见） | 显示商户余额，点击可刷新 |
| 用户头像 | 点击弹出「确认注销」对话框 |
| 🎨 主题色设置 | 打开右侧抽屉，可自定义全局主色 |

### 2.3 主题色设置

点击顶部 🎨 图标打开主题颜色抽屉：

- 使用颜色选择器自由选择任意颜色
- 或点击下方 6 个预设色块快速切换（蓝/绿/橙/红/紫/青）

主题色会实时应用到全局 Antd 组件，并持久化保存。

## 3. 商户管理

### 3.1 商户列表 `/merchant-manage/list`

- **查看列表**：分页展示所有商户（商户 ID、名称、身份等）
- **搜索**：在搜索框输入商户名称，列表会高亮匹配关键词
- **新增商户**：点击「新增商户」按钮，填写商户名称、邮箱、密码、商户类型（如「查重」）等信息后提交
- **操作列**：
  - **修改密码**：弹出 `UpdatePwd` 弹窗，重置该商户的登录密码
  - **权限设置**：弹出 `PermissionSettings` 弹窗，配置商户可使用的服务组（如 CrossCheck、Imagetwin 等的开关）

### 3.2 余额管理 `/merchant-manage/balance`

用于管理各商户的余额，可充值、扣减、查询余额变动记录。

## 4. 支付系统

### 4.1 金额统计 `/pay/stat`

按查重产品维度分别统计金额：

- **CrossCheck**：`/pay/stat/crosscheck`
- **Imagetwin**：`/pay/stat/imagetwin`

## 5. 查重系统

### 5.1 各产品订单管理

查重系统下包含四个产品线，结构一致：

| 产品 | 订单路径 | 异常订单路径 |
| --- | --- | --- |
| CrossCheck | `/scan/crosscheck/order` | `/scan/crosscheck/abnormal-orders` |
| Imagetwin | `/scan/imagetwin/order` | `/scan/imagetwin/abnormal-orders` |
| Turnitin(v2) | `/scan/history/order` | `/scan/history/abnormal-orders` |
| SangerboxScope | `/scan/duplisee/order` | `/scan/duplisee/abnormal-orders` |

- **订单页**：分页查看正常订单明细，支持搜索/筛选/导出
- **异常订单页**：处理失败或异常订单，可重试、退款或标记处理状态
- **菜单徽标**：当存在异常订单时，左侧菜单对应项会显示数字/红点提示

### 5.2 优惠码 `/scan/promocode`

- 新增 / 编辑 / 作废优惠码
- 设置优惠码的使用次数、有效期、适用产品

## 11. 商户端使用说明

商户登录后进入 `/merchant` 前缀下的页面，菜单与管理员不同（详见 `src/data/merchantMenu.json`）。

### 11.1 商户控制

#### 商户信息 `/merchant/control/information`

- 查看商户基本信息（名称、ID、身份）
- 查看当前余额（顶部 Header 也会显示，点击可刷新）

#### 购买商品 `/merchant/control/purchase`

- 卡片式展示可购买的商品（如 CrossCheck、Imagetwin 等），含单价与说明
- 选择购买数量后提交订单，系统自动扣减余额
- 下方展示该商户的历史订单列表

### 11.2 商品

#### 库存 `/merchant/goods/inventory`

查看商户名下各商品的库存数量。

#### 出售和消费 `/merchant/goods/sales-consumption`

查看商品的出售与消费明细记录。

#### 作废 `/merchant/goods/invalidated`

查看已作废的卡密/订单记录。

## 12. 通用操作

### 12.1 分页与筛选

- 列表页默认每页 10 条（见 `src/config.js` 中 `pagination.pageSize`）
- 支持切换每页条数
- 多数列表支持按关键词搜索、按时间范围筛选

### 12.2 文件下载

- 涉及导出的页面，点击「导出」按钮会触发浏览器下载
- 文件名优先取响应头 `Content-Disposition` 中的 `filename`，否则使用默认名

### 12.3 文件上传

- 支持文件上传的页面使用 `multipart/form-data` 提交
- 单文件过大（HTTP 413）会提示「上传的文件过大，请选择较小的文件进行上传」

### 12.4 错误提示

- 网络异常时会提示「您的网络似乎有问题，可能开启了 VPN/代理，或者请尝试刷新页面」
- 服务器错误（HTTP 500）会在控制台输出错误日志
- 所有接口错误均通过 Antd `message` 全局提示

### 12.5 注销登录

点击右上角头像 → 弹出「确认注销」对话框 → 点击「确认注销」：

- 调用后端登出接口
- 清空 Redux 状态与本地存储
- 跳转回登录页

## 13. 常见问题

### Q1：登录后页面空白或提示无权限？

- 确认账号角色是否正确（管理员 / 商户）
- 商户账号访问 `/` 路径会被 `PrivateRoute` 拦截并显示 403 页面
- 管理员账号访问 `/merchant` 路径同样会显示 403

### Q2：菜单项不显示？

- 部分模块在 `src/data/menu.json` 中被标记为 `"hidden": true`
- 如需显示，请联系开发人员修改菜单配置

### Q3：接口报 401 自动跳回登录页？

- 登录态已过期，请重新登录
- 系统会自动清空 `localStorage` 并跳转 `/login`

### Q4：商户余额不刷新？

- 点击顶部 Header 中的「当前余额」按钮可手动刷新
- 余额数据来源于后端 `refreshMerchantBalance` 接口

### Q5：长时间不操作被自动登出？

- 系统设置了 **30 分钟** 空闲超时自动登出（`useIdleLogout`）
- 任意鼠标移动、键盘按键、滚动、点击都会重置计时器

### Q6：部署后没有生效？

- 确认执行了 `npm run build` 重新打包
- 部署目标为 `Z:/users/panchengtian/online-project/admin2.sangerbox.com/live`
- 如需回退到上一版本，执行 `npm run rollback`
