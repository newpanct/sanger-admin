## 1. 登录

访问系统首页 `/login`，可见「桑格查重后台管理系统」登录页。

系统支持两种登录方式：

### 1.1 账号密码登录

1. 切换到 **账号密码登录** Tab
2. 输入 **邮箱** 与 **密码**
3. 点击「登录」按钮

登录成功后进入账号有权限的首页（一般为 `/dashboard`）。

### 1.2 微信扫码登录

1. 切换到 **微信扫码登录** Tab
2. 使用微信扫描页面中显示的二维码
3. 在手机端确认后，系统会自动轮询登录状态并跳转

> 若账号无后台权限，扫码后将提示失败。

### 1.3 登录态与超时

- 登录信息会持久化保存在浏览器 `localStorage`，关闭浏览器后无需重新登录。
- **空闲 30 分钟** 未任何鼠标/键盘/滚动/点击操作，系统将自动登出并跳回登录页。
- 后端返回 401 时也会自动清空登录态并跳转登录页。

## 2. 系统总览（管理员）

### 2.1 仪表盘 `/dashboard`

进入管理员后台首页即可看到仪表盘，包含：

- **统计卡片**：今日单量/营收、本月单量/营收、累计订单/营收；数字从 0 递增到接口终值；本月卡片展示较上月涨跌
- **异常订单概览**：CrossCheck / ImageTwin / Turnitin / SangerboxScope 各自的待处理数量，点击卡片跳转对应异常订单页
- **月订单 / 月营收柱状图**：颜色跟随当前主题；鼠标悬停显示当月订单数或金额
- **最新公告**：预览当前生效横幅，可跳转「公告管理」
- **刷新按钮**：手动重新拉取统计与公告

> 异常订单数量会同步显示在左侧菜单对应项的红点徽标上。

### 2.2 顶栏功能

从左到右依次为：

| 按钮 | 功能 |
| --- | --- |
| 折叠/展开菜单 | 收起或展开左侧侧边栏 |
| 进入/退出全屏 | 切换浏览器全屏模式 |
| ☀️ / 🌙 切换 | 浅色 / 深色主题切换 |
| 当前余额（仅商户可见） | 显示商户余额，点击可刷新 |
| 用户头像 | 点击弹出「确认注销」对话框 |
| 🎨 主题色设置 | 打开右侧抽屉，可自定义全局主色 |

### 2.3 主题色设置

点击顶部 🎨 图标打开主题颜色抽屉：

- 使用颜色选择器自由选择任意颜色
- 或点击下方 6 个预设色块快速切换（蓝/绿/橙/红/紫/青）

主题色会实时应用到按钮、链接、复制图标、仪表盘柱状图等，并持久化保存。

## 3. 商户管理

### 3.1 商户列表 `/merchant-manage/list`

- **查看列表**：分页展示所有商户（商户 ID、名称、身份、邮箱等）
- **搜索**：在搜索框输入商户名称，列表会高亮匹配关键词
- **创建商户**：填写商户名称、邮箱、密码、权限类别（如「查重」）后提交
- **操作列**：
  - **修改密码**：重置该商户的登录密码
  - **权限管理**：配置商户可使用的服务组

订单号、邮箱等长文本旁有复制图标，过长会省略，复制按钮不会被裁切。

### 3.2 余额管理 `/merchant-manage/balance`

用于管理各商户的余额，可充值、扣减、查询余额变动记录。

## 4. 支付系统

### 4.1 金额统计 `/pay/stat`

按查重产品分别统计：

- **CrossCheck**：`/pay/stat/crosscheck`
- **Imagetwin**：`/pay/stat/imagetwin`
- **SangerboxScope**：`/pay/stat/sangerboxscope`

每个页面顶部为统计卡（订单数、销售额、退款等，带计数动画）：

- 订单数、销售额、退款订单数、退款金额：按**当前列表页**汇总
- **待退款金额**、**净收入**：取接口 `data` 上的总览字段，不是当前页加总

支持按月份筛选。表格可展开行查看该日退款订单明细。

### 4.2 企业/组织充值 `/pay/stat/enterprise-recharge`

已支付单数、累计支付金额，以及充值订单列表。

### 4.3 个人账户明细 `/pay/personal-account-detail`

按账号查询个人账户流水。

## 5. 查重系统

### 5.1 各产品订单管理

查重系统下包含四个产品线，结构一致：

| 产品 | 订单路径 | 异常订单路径 |
| --- | --- | --- |
| CrossCheck | `/scan/crosscheck/order` | `/scan/crosscheck/abnormal-orders` |
| Imagetwin | `/scan/imagetwin/order` | `/scan/imagetwin/abnormal-orders` |
| Turnitin(v2) | `/scan/history/order` | `/scan/history/abnormal-orders` |
| SangerboxScope | `/scan/duplisee/order` | `/scan/duplisee/abnormal-orders` |

- **订单页**：分页查看订单明细，支持搜索/筛选；部分服务可删除订单（删除前确认）
- **异常订单页**：失败任务可「提交」重试、「忽略」或「退款」
- **菜单徽标**：存在异常订单时，左侧菜单对应项会显示数字提示

### 5.2 异常订单退款

退款弹窗需填写 **退款原因** 和 **管理员密码**。

- 可点击「快捷选择」中的原因一键填入
- 没有合适原因时，点击 **去自定义退款原因** 跳转到退款理由管理（需有该菜单权限）
- 暂无快捷原因时，弹窗内也会提示可前往管理页添加

### 5.3 优惠码 `/scan/promocode`

- 查看优惠码使用状态、启用状态
- 新增 / 编辑等能力以页面实际按钮为准

## 7. 邮件模板管理

路径：`/email`

- 管理各类邮件模板（验证码、通知等）
- 模板中支持变量占位符，例如：
  - `{{subject}}` 邮件主题
  - `{{companyName}}` 公司名
  - `{{verificationCode}}` 验证码
  - `{{templateTypeDescription}}` 验证码类型描述
  - `{{currentYear}}` 当前年份
- 系统在 `src/config.js` 中提供默认 HTML 模板，可在页面中编辑覆盖

## 11. 系统管理与退款理由

有对应菜单权限时可见。

### 11.1 菜单 / 角色

- **菜单列表**：维护目录、菜单、按钮；支持排序
- **角色管理**：维护角色名称、状态等
- **角色菜单**：为角色分配菜单权限

**删除菜单或角色**为两次确认，防止误触：

1. 第一层确认对象，可点「下一步」
2. 第二层必须输入 **完整名称**，「确认删除」才会可点

删除带有子级的目录/菜单时，第一层会提示子级一并移除。删除成功后侧栏会按最新权限刷新。

### 11.2 退款理由 `/refund-reason`

维护异常订单退款弹窗中的快捷原因。在此新增后，退款弹窗「快捷选择」即可使用。

## 12. 商户端使用说明

商户登录后侧栏菜单与管理员不同（兜底配置见 `src/data/merchantMenu.json`），登录成功后会按菜单进入有权限的首页。

### 12.1 商户控制

#### 商户信息 `/control/information`

- 查看商户基本信息（名称、ID、身份）
- 查看当前余额（顶部 Header 也会显示，点击可刷新）

#### 购买商品 `/control/purchase`

- 卡片式展示可购买的商品（如 CrossCheck、Imagetwin 等），含单价与说明
- 选择购买数量后提交订单，系统自动扣减余额
- 下方展示该商户的历史订单列表

### 12.2 商品

#### 库存 `/goods/inventory`

查看商户名下各商品的库存数量。

#### 出售和消费 `/goods/sales-consumption`

查看商品的出售与消费明细记录。

#### 作废 `/goods/invalidated`

查看已作废的卡密/订单记录。

## 13. 通用操作

### 13.1 分页与筛选

- 列表页默认每页 10 条（见 `src/config.js` 中 `pagination.pageSize`）
- 支持切换每页条数
- 多数列表支持按关键词搜索、按月份或时间范围筛选

### 13.2 复制长文本

订单号、邮箱等字段使用省略显示，右侧复制图标始终可见，颜色跟随主题。

### 13.3 文件下载

- 涉及导出的页面，点击「导出」按钮会触发浏览器下载
- 文件名优先取响应头 `Content-Disposition` 中的 `filename`，否则使用默认名

### 13.4 文件上传

- 支持文件上传的页面使用 `multipart/form-data` 提交
- 单文件过大（HTTP 413）会提示上传文件过大

### 13.5 错误提示

- 网络异常时会提示检查网络或关闭 VPN
- 所有接口错误均通过 Antd `message` 全局提示

### 13.6 注销登录

点击右上角头像 → 弹出「确认注销」对话框 → 点击确认：

- 调用后端登出接口
- 清空 Redux 状态与本地存储
- 跳转回登录页

## 14. 常见问题

### Q1：登录后页面空白或侧栏没有某个功能？

- 当前账号没有对应菜单权限，请管理员在角色/菜单中开通
- 部分模块在菜单配置中标记为隐藏，需有权限的人调整菜单

### Q2：接口报 401 自动跳回登录页？

- 登录态已过期，请重新登录
- 系统会自动清空 `localStorage` 并跳转 `/login`

### Q3：商户余额不刷新？

- 点击顶部 Header 中的「当前余额」按钮可手动刷新

### Q4：长时间不操作被自动登出？

- 系统设置了 **30 分钟** 空闲超时自动登出
- 任意鼠标移动、键盘按键、滚动、点击都会重置计时器

### Q5：退款弹窗没有快捷原因？

- 到「退款理由管理」添加
- 或在退款弹窗中点击「去自定义退款原因」

### Q6：改了主题色，柱状图没变？

- 刷新仪表盘；柱状图会按当前主题色重绘

### Q7：部署后没有生效？

- 确认执行了 `npm run build` 重新打包（`npm run deploy` 会先构建）
- 部署目标为 `Z:/users/panchengtian/online-project/admin2.sangerbox.com/live`
- 如需回退到上一版本，执行 `npm run rollback`

### Q8：局域网打不开开发地址？

- 确认已 `npm start`，防火墙放行 **8002**
- 使用开发机局域网 IP 访问（不是只开 localhost）
- 线上请走正式域名
